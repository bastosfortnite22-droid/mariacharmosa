# Studio Maria Chamosa - Diretório de Fotos Reais

Coloque suas fotos reais aqui com os seguintes nomes para exibição automática:
- hero.jpg (ou hero.png / hero.webp) -> Foto principal da seção Hero
- espaco-01.jpg -> Foto do espaço/salão
- cabelo-01.jpg -> Foto de serviços de cabelo (corte/escova/mechas)
- cabelo-02.jpg -> Foto de coloração/mechas
- unhas-01.jpg -> Foto de manicure / nail design
- unhas-02.jpg -> Foto de pedicure / nail design
- sobrancelhas-01.jpg -> Foto de design de sobrancelhas
- estetica-01.jpg -> Foto de procedimentos de estética

Você também pode carregar as fotos diretamente na interface através do botão "Gerenciar Fotos Reais" no rodapé ou na galeria!
